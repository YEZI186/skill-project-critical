# 软著源码提取与格式整理工具 版本更新说明

**软件名称**：软著源码提取与格式整理工具
**用途**：扫描代码文件 → 格式清洗 → 生成 Markdown 源代码文档，用于软件著作权申请材料整理

---

## V2.0（2026-10-12）

**形态变化：图形界面 → 无界面命令行**（旧 GUI 程序、打包产物与备份已按用户要求清除，不再保留归档）

- 新入口 `codescrape.py`：在**项目根目录**零参数执行 `python <skill目录>/code-scrape/codescrape.py run`，自动产出清单与汇总文档，不再需要选择文件夹、勾选文件、点击"开始整理"
- 子命令：`run`（清单+汇总）/ `list`（仅清单）/ `pack`（仅汇总）/ `stat`（只统计）/ `scan`（诊断）；项目名默认取目录名中的中文，可用 `--project-name` 校正为登记全称
- **输出文档不再写头部统计**：汇总 md 只含按清单顺序连续拼接的源码正文（无标题、无统计列表、无 `---`），统计改为**生成完成后输出到会话**，`--stats-json` 可落盘；如需旧版头部用 `--keep-header` 临时回退
- **行数统计算法重写**（单遍词法状态机，覆盖 60+ 扩展名 / 30+ 语言），修复四类硬缺陷：① 字符串内的 `/*`、`/**` 被当成块注释开始并**吞掉后续行**（`WebConfig.java` 旧 26 → 新 47）；② `.wxml` 完全不识别 HTML 注释（多算）；③ `.vue` 只认 `<!-- -->`、漏识别 `<script>` 内 JS 注释；④ `.sql` 不认 `--` 行注释。新增嵌套块注释、heredoc、跨行字符串、SFC 分块与未闭合容错
- **四口径统计**：物理行 / 空行 / 注释行 / 有效代码行，恒等式 `物理行 = 空行 + 注释行 + 有效代码行`；口径固定为"多行字符串与 docstring 计注释、混合行计代码、Shebang 与编码声明计注释"
- **统计与产物对账**：`md 正文总行数 = Σ各文件物理行 + 失败占位行 +（可选）文件分隔行`，每次运行自检，不平即报内部错误
- **清单规则同步升级**：剪枝 `tools/`、`scripts/`、`migrations/`、`_legacy/`（防御性剪枝条目，目录本身已清除）；前端不再采集 `.html`；`env.js`/`next-env.d.ts` 等归配置；纯 import/re-export 的 `__init__.py`、`index.ts` 判空包剔除；同名数字变体（`start_server2.py`）剔除；`manage.py` 与 Django `settings.py` 剔除；演示/模拟设施目录（`*_simulator/`、`*_emulator/`、`*_demo/`、`demos/`、`samples/`、`fixtures/`）剔除（**不匹配裸 `demo/`**，避免误杀 `com/demo/` 这类包路径）；新增项目级白名单 `--keep-path`
- **排序双模式**：Spring Boot 型走"全局类别优先"；NestJS 型（`*.controller.*`/`*.service.*` 等后缀 ≥3 个且跨 ≥2 目录）走"业务模块优先"；Next.js 的 `pages/_app.tsx`、`_document.tsx` 纳入入口
- **与历史数字对照**：`--legacy-report` 并列"V1.6 旧算法数字 + 逐条差异归因"（旧算法仅作只读快照 `codescrape/legacy_count.py`，**不参与任何产出**）。实测水电项目 70 文件：旧 3304 / 新 3288，逐行差异 58 条全部归因（`WebConfig.java` +21、12 个 `.wxml` 的 HTML 注释 −37）
- **不打包 exe**（本期不做；CLI 直接以 Python 运行，旧 exe 与 PyInstaller 打包产物已于 V2.0 清理时删除）
- 配置：`settings.json` 保留（CLI 只读，不回写）；旧版脚本目录的 `忽略规则.gitignore` 已删除，忽略规则改为**项目根自备同名文件**或 `--rules` 指定（都不存在则按无规则处理，不创建文件）

## V1.6（2026-08-12）

- 整理输出的源代码文档默认完全不留空行（首选项"空行压缩模式"默认值改为 0），与旧版输出风格一致，避免文档中出现多余空行
- 空行压缩模式设置项保留：可在首选项中切换 0/1/2（不留 / 保留一个 / 保留两个）

## V1.5（2026-08-12）

- 修复空行压缩设置失效：首选项中"空行压缩模式"（0/1/2）现在真实生效（0=不留空行、1=保留一个空行、2=保留两个空行），文件开头/结尾空行不计入
- 修复忽略规则热更新与处理流程冲突：处理/扫描进行中只重载规则不自动重扫，新增扫描并发保护，避免勾选状态被破坏
- 修复过滤关键字与重扫结果不一致：重扫后自动应用当前过滤关键字，且输入过滤不再触发重复扫描
- 修复自动加载核心代码名称覆盖手动勾选：过滤操作不再清空手动勾选状态
- 统一输入选中/自动加载的文件匹配逻辑为公共方法，删除冗余索引构建代码
- 清理死代码：删除未使用的语言映射表、恒等映射、失效日志文案
- **新增 EXE 打包**：PyInstaller 单文件打包，规则文件（忽略规则.gitignore）与配置文件（settings.json）固定在 exe 所在目录，可持久化保存

## V1.4（2026-08）

- 输出文件直接生成到首选项指定的输出文件夹中，不再额外创建"项目名"子文件夹
- 输出文件名中的项目名仅保留中文字符（去除数字与符号），无中文时自动兜底为"项目"
- 文件名模板占位符统一为中文版本（`{项目名}`、`{类型}`），移除英文占位符（`{project}`、`{type}`）兼容处理，旧配置加载时自动迁移，杜绝双版本冲突
- 设置窗口文件名预览与实际保存结果保持一致

## V1.3（2026-08）

- 新增输出配置功能：输出文件夹（留空默认扫描目录根）、输出类型、文件名模板自定义
- 文件名模板支持占位符 `{类型}` / `{项目名}`，仅允许中文占位符，非法占位符保存时拦截提示
- 新增同名文件处理勾选：勾选"同名文件直接替换"则覆盖，不勾选则自动新增序号文件（如 名称(1).md）
- 输出文件名模板默认值调整为 `{项目名}`，默认输出"项目名.md"
- 输入选中弹窗显示"已读取核心代码文件：N 个"，数量为预填内容中的有效条目数
- 旧版输出目录绝对路径配置自动兼容（仅取其文件夹名）

## V1.2（2026-08）

- 核心代码名称文件智能查找：优先扫描根目录，其次递归扫描 out 文件夹；跳过前端/后端代码文件夹（前端、前端代码、后端、后端代码、frontend、backend）
- 输入选中框自动预填所有核心代码名称文件内容（UTF-8 优先、GBK 兜底），多文件按查找顺序拼接
- 修复 out 目录在 Windows 下大小写不敏感导致的重复扫描问题

- 设置窗口内嵌规则编辑器：直接预览编辑保存，无需外部编辑器
- 规则文件热更新：修改保存后自动重新加载并自动重扫，无需重启程序

## V1.0

- 基础功能：扫描目录代码文件、忽略规则过滤、格式清洗（空行合并、去除尾随空格、文件大小上限控制）
- 读取"核心代码名称"文件预填输入列表，按顺序整理
